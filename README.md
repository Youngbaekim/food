# YB Family Food Diary

가족 식사 일기 앱 (PWA) — 음식 사진 1장 + 제목·내용, 아침·점심·저녁 끼니마다 1건씩 가족이 함께 기록

## 실행 방법 (PowerShell)

```
cd C:\dev\food-diary
npm install      # 처음 한 번만
npm run dev      # 개발 서버 → 화면에 나오는 주소를 브라우저로 열기
```

- 점검용 가짜 저장소: 개발 서버 주소 끝에 `?demo` (로그인 없이 화면 점검, 새로고침하면 지워짐)
- 배포: `main` 브랜치에 올리면 GitHub Actions가 자동으로 GitHub Pages에 배포
- 새 버전 안내를 띄우려면 `public/sw.js`의 `VERSION`과 `package.json`의 `version`을 올린 뒤 배포

## 구성

| 항목 | 내용 |
|---|---|
| 로그인·동기화 | YB-EverNote와 같은 Firebase 프로젝트(yb-evernote), Google 로그인, 허용 목록 가족 계정만 |
| 공유 방식 | 가족 공용 일기 — 모두 함께 보고, 수정·삭제는 올린 사람만 |
| 저장 위치 | Firestore `family/yb/meals/{날짜_끼니}`(기록·미리보기) · `family/yb/mealImages/{같은 ID}`(사진) |
| 끼니 구분 | 아침(11시 이전) · 점심(16시 이전) · 저녁(16시 및 그 이후) — 문서 ID가 `날짜_끼니`라서 하루 최대 3건 |
| 사진 | 1건에 1장(촬영·앨범·PC 붙여넣기/끌어놓기), 올리기 전 긴 변 1,280px·200KB 이하로 압축(WebP/JPEG 중 작은 쪽) |
| 일시 | 올린 시각 자동 기록, 수정 가능 — 끼니가 바뀌면 그 끼니가 비어 있을 때만 옮김, 앞날짜 불가 |
| 제목 | 기본 `2026.11.07 (토) 점심` + 직접 쓴 제목이 있으면 목록에 함께 표시 |
| 화면 | PC: 사진 왼쪽·기록 오른쪽 / 휴대폰: 사진 위·기록 아래 |
| 배포 주소 | https://youngbaekim.github.io/food/ (저장소 youngbaekim/food) |
